## Première Connexion

1. Accédez à l'application via votre navigateur (par défaut : http://localhost:3000)
2. Connectez-vous avec les identifiants de l'administrateur que vous avez configurés dans le fichier `.env`
3. Changez votre mot de passe après la première connexion

## Gestion des Livres Audio

### Ajouter des Livres
1. Cliquez sur "Ajouter des livres" dans la barre latérale
2. Sélectionnez la source (fichiers locaux, dossier, etc.)
3. Laissez l'application analyser et importer les métadonnées
4. Vérifiez et corrigez les métadonnées si nécessaire
5. Cliquez sur "Importer"

### Modifier les Métadonnées
1. Recherchez le livre dans votre bibliothèque
2. Cliquez sur "Modifier"
3. Mettez à jour les champs nécessaires (titre, auteur, couverture, etc.)
4. Enregistrez les modifications

### Supprimer des Livres
1. Sélectionnez le(s) livre(s) à supprimer
2. Cliquez sur "Supprimer"
3. Confirmez la suppression

## Lecture des Livres

### Contrôles de Lecture
- Lecture/Pause
- Avance/Retour rapide (10 secondes)
- Vitesse de lecture (0.5x à 2.5x)
- Minuteur de sommeil

### Signets et Notes
- Ajoutez des signets à des moments précis
- Prenez des notes pendant l'écoute
- Exportez vos notes et signets

### Synchronisation Multi-appareils
- Votre progression est automatiquement synchronisée
- Reprenez votre lecture là où vous vous êtes arrêté sur n'importe quel appareil

## Gestion des Utilisateurs

### Ajouter un Utilisateur
1. Allez dans "Paramètres" > "Utilisateurs"
2. Cliquez sur "Ajouter un utilisateur"
3. Remplissez les informations requises
4. Définissez les permissions
5. Envoyez l'invitation

### Gérer les Permissions
- Administrateur : Accès complet à toutes les fonctionnalités
- Éditeur : Peut ajouter/modifier des livres mais pas gérer les utilisateurs
- Lecteur : Peut uniquement lire les livres

## Dépannage

### Problèmes Courants

#### La lecture ne démarre pas
- Vérifiez votre connexion Internet
- Rafraîchissez la page
- Videz le cache de votre navigateur

#### Problème de Synchronisation
- Vérifiez que vous êtes connecté à Internet
- Rafraîchissez la page
- Vérifiez les journaux du serveur pour les erreurs

#### Problème de Connexion
- Vérifiez vos identifiants
- Assurez-vous que votre compte est actif
- Réinitialisez votre mot de passe si nécessaire
