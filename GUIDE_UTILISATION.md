## Premiers Pas

### Création de Compte

1. Cliquez sur "Créer un compte" sur la page d'accueil
2. Remplissez le formulaire avec vos informations
3. Vérifiez votre adresse email en cliquant sur le lien reçu
4. Connectez-vous avec vos identifiants

### Connexion

1. Rendez-vous sur la page de connexion
2. Entrez votre adresse email et votre mot de passe
3. Cliquez sur "Se connecter"
4. Si activé, validez la connexion à deux facteurs

### Récupération de Mot de Passe

1. Sur la page de connexion, cliquez sur "Mot de passe oublié ?"
2. Entrez votre adresse email
3. Suivez les instructions dans l'email reçu pour réinitialiser votre mot de passe

## Tableau de Bord

### Vue d'Ensemble

Le tableau de bord affiche :
- Vos livres récemment écoutés
- Votre progression de lecture
- Les nouveautés de votre bibliothèque
- Les recommandations personnalisées

### Navigation

- **Bibliothèque** : Accédez à tous vos livres audio
- **Découvrir** : Explorez de nouveaux contenus
- **Téléchargements** : Gérez vos téléchargements hors ligne
- **Recherche** : Trouvez rapidement un livre ou un auteur

### Profil Utilisateur

Cliquez sur votre photo de profil pour :
- Voir et modifier votre profil
- Accéder aux paramètres
- Gérer votre abonnement
- Vous déconnecter

## Gestion des Livres Audio

### Ajouter des Livres

1. Cliquez sur "Ajouter des livres"
2. Sélectionnez la source (fichiers locaux, dépôt, etc.)
3. Suivez les instructions pour l'importation
4. Les métadonnées seront extraites automatiquement

### Organiser la Bibliothèque

- **Collections** : Créez des collections personnalisées
- **Étiquettes** : Ajoutez des étiquettes pour un classement personnalisé
- **Recherche** : Utilisez les filtres pour trouver rapidement

### Écouter des Livres

1. Cliquez sur un livre pour ouvrir sa page détaillée
2. Cliquez sur "Lire" pour commencer la lecture
3. Utilisez les contrôles de lecture pour :
   - Mettre en pause/reprendre
   - Avancer/reculer de 30 secondes
   - Ajuster la vitesse de lecture
   - Activer le mode nuit

## Paramètres

### Préférences Utilisateur

- **Profil** : Modifiez vos informations personnelles
- **Sécurité** : Changez votre mot de passe, activez l'authentification à deux facteurs
- **Thème** : Choisissez entre clair, sombre ou automatique

### Paramètres de Lecture

- **Vitesse de lecture** : Ajustez entre 0.5x et 3x
- **Minuteur de sommeil** : Programmez l'arrêt automatique
- **Saut en avant/arrière** : Personnalisez la durée des sauts

### Notifications

- **Email** : Activez/désactivez les notifications par email
- **Application** : Gérez les notifications push
- **Abonnements** : Choisissez les types de notifications que vous souhaitez recevoir

## Fonctionnalités Avancées

### Synchronisation Multi-appareils

Votre bibliothèque et votre progression sont synchronisées sur tous vos appareils. Connectez-vous avec le même compte pour continuer là où vous vous étiez arrêté.

### Listes de Lecture

Créez des listes de lecture personnalisées :
1. Allez dans "Bibliothèque" > "Listes de lecture"
2. Cliquez sur "Nouvelle liste"
3. Donnez un nom à votre liste
4. Ajoutez des livres depuis votre bibliothèque

### Marque-pages et Notes

- **Marque-pages** : Marquez des moments importants dans vos livres
- **Notes** : Prenez des notes pendant l'écoute
- **Surbrillages** : Mettez en évidence des passages

## Dépannage

### Problèmes Courants

#### La lecture ne démarre pas
- Vérifiez votre connexion internet
- Essayez de redémarrer l'application
- Vérifiez que le format du fichier est pris en charge

#### Problème de synchronisation
- Assurez-vous d'être connecté à internet
- Rafraîchissez la page
- Vérifiez que vous utilisez la dernière version de l'application

#### Problème de connexion
- Vérifiez vos identifiants
- Essayez de réinitialiser votre mot de passe
- Assurez-vous que votre compte est vérifié
